# Castle Escape Game

A short Python terminal adventure. Start in the hallway and choose a door.
Visit the kitchen to discover a silver key, or head straight to the garden to win.

## Run

Requires Python 3. No third-party packages are needed.

```sh
python3 Castle_escape_game.py
```

Type `kitchen` or `garden` at the prompt. In the kitchen, press Enter to
return to the hallway. Invalid choices leave you in the hallway so you can
try again. Press Ctrl+C to quit.
